DelMonHp

参数1=百分比或切割值(值不能大于21亿，百分比不能超过100，负数无效)

参数2=0:以当前HP的百分比 1:以参数1的值切割 2::以最大HP的百分比

参数3=0不判断嘲讽 1判断嘲讽过的怪才切割

参数4=0都切割 1:本次切割只切割角色 2:本次切割只切割英雄 3:本次切割只切割怪物

参数5=分母基数(<=100等于100)

参数6=是否播放切割动画(空或0不播放,1播放,播放必备补丁素材)

例子1：

#ACT
；本次切割只切割怪物10点HP
DELMONHP 10 1 0 3

例子2：

#ACT
；本次切割只切割人物当前血量百分之8
DELMONHP 8 0 0 1

例子3：

#ACT
；本次切割只切割人物当前血量千分之8
DELMONHP 8 0 0 1 1000

DelMonHpEx

参数1=百分比或切割值(值不能大于21亿，百分比不能超过100，负数无效)

参数2=0:以当前HP的百分比 1:以参数1的值切割 2:以最大HP的百分比

参数3=0不判断嘲讽 1判断嘲讽过的怪才切割

参数4=0以自身范围 1以攻击目标范围

参数5=X坐标

参数6=Y坐标

参数7=范围

参数8=0都切割 1:本次切割只切割角色，2:本体切割只切割英雄，3:本次切割只切割怪物。

参数9=分母基数(<=100等于100)

参数10=是否播放切割动画(空或0不播放,1播放,播放必备补丁素材)

例子1：
#ACT

;切割自身1格坐标范围的怪物10/100 HP
DELMONHPEX 10 2 0 0 <$X> <$Y> 1 3

例子2：
#ACT

;切割自身1格坐标范围的怪物10/1000 HP
DELMONHPEX 10 2 0 0 <$X> <$Y> 1 3 1000
