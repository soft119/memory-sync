### 骷髅精灵刷新脚本（确认可用）

```
[@OnKillMob]
#IF
EQUAL <$KILLMONNAME> 骷髅
#OR
EQUAL <$KILLMONNAME> 骷髅战士
#OR
EQUAL <$KILLMONNAME> 掷斧骷髅
RANDOM 100
#ACT
MonGenEx <$MAP> <$X> <$Y> 骷髅精灵 0 1 0 251
SENDMSG 6 触发稀有事件！骷髅精灵出现了！
```

### 关键踩坑：#CASE/#IF 分支写法有 BUG
- `#CASE/#IF + GOTO` 跳转写法**不能正确触发**骷髅精灵刷新
- 必须使用 `#OR` 写法，3 种怪物共享同一概率池
- `RANDOM N` = 1/N 概率，N 越大概率越低

### MonGenEx 命令格式
```
MonGenEx <地图> <X> <Y> <怪物名> <范围> <数量> <移动方式> <怪物IDX>
```
- 最后参数 IDX 可以省略（用怪物名匹配）
- 用 `<$MAP> <$X> <$Y>` 在击杀位置附近刷新

原命令：`MonGenEx <$PLAYERMAP> <$PLAYERX> <$PLAYERY> 骷髅精灵 5 1 0 1029`

**第8个参数是名称颜色！不是怪物IDX！**
